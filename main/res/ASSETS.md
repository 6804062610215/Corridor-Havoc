# รายการไฟล์ภาพและเสียง (ชั่วคราว)

ไฟล์ทั้งหมดในโฟลเดอร์นี้เป็น **ไฟล์ชั่วคราว (placeholder)** ที่สร้างด้วยโปรแกรม
ถ้าจะเปลี่ยนเป็นไฟล์จริง ให้ **ใช้ชื่อไฟล์เดิม** แล้ววางทับได้เลย ไม่ต้องแก้โค้ด

> โค้ดหาไฟล์ด้วย `getResource("/res/...")` จาก classpath ใช้ได้ทั้งตอนรัน `java Main` ในโฟลเดอร์ `main` และตอนรัน `CorridorHavoc.jar`
> **เปลี่ยนรูปหรือเสียงแล้ว ต้องรัน `build.bat` ใหม่** เพื่อให้ไฟล์ใหม่เข้าไปอยู่ใน `CorridorHavoc.jar`
> ถ้าหาไฟล์ไม่เจอ เกมจะไม่ปิด แต่จะพิมพ์ `Cannot load ...` ใน terminal
> - รูปที่หาไม่เจอจะแสดงเป็นตารางสีชมพูสลับดำแทน
> - เสียงที่หาไม่เจอจะเงียบ

**ข้อกำหนดเมื่อเปลี่ยนรูป**
- ต้องเป็นไฟล์ **PNG ที่พื้นหลังโปร่งใส** (พิกเซลที่โปร่งใสจะไม่ถูกวาด)
- ภาพควรเป็นสี่เหลี่ยมจัตุรัส ใช้ขนาดเท่าไหร่ก็ได้ เช่น 32×32 หรือ 64×64 เกมจะย่อขยายให้เอง
- ภาพศัตรูควรเต็มกรอบตั้งแต่บนลงล่าง
- ภาพไอเทมและอุปสรรค (หลุมไฟ หนาม ถัง) ควรวาดชิดขอบล่าง เพราะวางอยู่บนพื้น
- ภาพลูกไฟ กระสุน และไฟปากกระบอก ควรอยู่ตรงกลางภาพ
- ภาพปืนควรให้ปลายกระบอกอยู่ตรงกลางขอบบนของภาพ และให้มือหรือแขนอยู่ด้านล่าง
  - เกมวาดปืนขนาด 200×200 ไว้กลางจอด้านล่าง
  - ส่วนล่างของภาพปืนจะถูกแถบ HUD บังไว้
- ถ้าอยากให้ศัตรูตัวใหญ่หรือเล็กลง ให้แก้ค่าใน `getSizeScale()` ของคลาสศัตรูนั้น

**ข้อกำหนดเมื่อเปลี่ยนเสียง**
- ต้องเป็นไฟล์ **.wav (PCM 16-bit)** เพราะ Java เล่นไฟล์ MP3 เองไม่ได้
  - ถ้ามีไฟล์ MP3 ให้แปลงเป็น WAV ก่อน เช่น ใช้โปรแกรม Audacity
- เพลงพื้นหลังควรตัดให้ต่อกันได้พอดีตอนวนซ้ำ
- ถ้าจะเพิ่มเสียงใหม่ ให้ทำ 2 อย่าง
  1. ใส่ชื่อไฟล์ลงในรายการ `ALL_SOUNDS` ในคลาส `Sound`
  2. เรียก `Sound.play("ชื่อไฟล์.wav")` ในจุดที่ต้องการให้เสียงดัง

## คลาสที่เกี่ยวข้อง

- `ImageLoader` — โหลดรูปจาก `res/images/` ถ้าโหลดไม่ได้จะคืนรูปตารางสีชมพูสลับดำแทน
- `Sound` — โหลดเสียงทั้งหมดตอนเปิดเกม มีเมธอด
  - `play()` เล่นครั้งเดียว
  - `loop()` เล่นวนซ้ำ
  - `stop()` หยุดเล่น
- `SpriteData` — เก็บข้อมูลของสิ่งที่จะวาดในฉาก (ตำแหน่ง รูป ขนาด และระยะห่างจากผู้เล่น)

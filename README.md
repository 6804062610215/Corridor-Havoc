# ทางเดินนรก (Corridor Havoc)

เกมยิงมุมมองบุคคลที่หนึ่งแนว Retro FPS คล้ายเกมยุค Doom เขียนด้วยภาษา Java (Swing) ทั้งหมด ไม่ใช้ Game Engine
ภาพ 3 มิติสร้างจากแผนที่ 2 มิติด้วยเทคนิค Ray Casting

ผู้เล่นต้องฝ่าด่าน 3 ด่าน ยิงศัตรูที่เข้ามาเป็นคลื่นให้หมด หลบอุปสรรค และบริหาร HP กับกระสุนให้พอ จนถึงบอสตัวสุดท้าย

## วิธีเปิดเกม

1. ติดตั้ง **Java 8 ขึ้นไป** (ถ้ายังไม่มี ดาวน์โหลดฟรีได้ที่ [adoptium.net](https://adoptium.net))
2. ดาวน์โหลดโปรเจกต์นี้ (ปุ่ม **Code → Download ZIP**) แล้วแตกไฟล์
3. ดับเบิลคลิก **`Play.bat`**

ถ้าไม่ใช่ Windows ให้เปิด terminal ในโฟลเดอร์โปรเจกต์แล้วรัน

```bash
java -jar CorridorHavoc.jar
```

## เนื้อหาในเกม

**อาวุธ** เลือก 1 จาก 3 แบบก่อนเริ่มเกม

| อาวุธ | ดาเมจต่อนัด | ยิงได้ (นัด/วินาที) | แม็ก / กระสุนสำรองเริ่มต้น | วิธียิง |
| --- | --- | --- | --- | --- |
| Assault (ปืนกล) | 5 | ~6.7 | 40 / 200 | กดค้างยิงต่อเนื่อง |
| Shotgun | 25 | ~1.7 | 6 / 24 | คลิกทีละนัด |
| Sniper | 40 | ~1.3 | 5 / 20 | คลิกทีละนัด |

**ด่าน** แต่ละด่านใช้แผนที่ สีฉาก และอุปสรรคต่างกัน

| ด่าน | อุปสรรค | คลื่น |
| --- | --- | --- |
| 1 The Corridors | หลุมไฟ | 3 |
| 2 The Laboratory | หลุมไฟ, กับดักหนาม | 4 |
| 3 The Demon's Lair | หลุมไฟ, กับดักหนาม, ถังระเบิด | 4 + บอส |

- **ศัตรู:** Grunt (ประชิดตัว), Shooter (ยิงลูกไฟระยะไกล หลบได้), Boss (ตัวสุดท้าย)
- **อุปสรรค:** หลุมไฟลวกเมื่อยืนทับ, กับดักหนามยื่นขึ้นลงเป็นจังหวะ, ถังระเบิดขวางทางและยิงให้ระเบิดได้
- **ไอเทม:** ชุดปฐมพยาบาล (HP +30), กระสุนเสริม (+20 นัด, ปืนกล Assault ได้ +80 นัด), บัฟดาเมจ ×2 นาน 10 วินาที

## สร้างเกมจากซอร์สโค้ด

ต้องมี **JDK 8 ขึ้นไป** (มี `javac` และ `jar`)

- ดับเบิลคลิก **`build.bat`** จะได้ไฟล์ `CorridorHavoc.jar` ใหม่ (ต้องรันใหม่ทุกครั้งที่แก้โค้ด รูป หรือเสียง)
- หรือคอมไพล์แล้วรันเองในโฟลเดอร์ `main`

```bash
cd main
javac --release 8 -encoding UTF-8 *.java
java Main
```

## แนวคิด OOP ที่ใช้

- **Inheritance & Polymorphism:** `Enemy` เป็นคลาสแม่ของ `Grunt`, `Shooter`, `Boss` และ `Obstacle` เป็นคลาสแม่ของ `FirePit`, `SpikeTrap`, `ExplosiveBarrel` เกมเรียก `update()` ผ่านคลาสแม่โดยไม่ต้องรู้ชนิดจริง
- **Abstract class:** `Enemy` และ `Obstacle` มี abstract method ให้คลาสลูก implement เอง
- **Interface:** `ProjectileSpawner` (implement โดย `WaveManager`) และ `ActionListener`, `KeyListener`, `MouseListener`, `MouseMotionListener`
- **Encapsulation & Composition:** `GamePanel` ประกอบด้วย `Renderer`, `Hud`, `MenuScreen`, `InputHandler`, `WaveManager`, `Player` แต่ละคลาสทำหน้าที่เดียว
- **Enum:** `Weapon`, `GameState`, `ItemType`

อัลกอริทึมหลัก: Ray Casting แบบ DDA, การวาด Sprite ด้วย zBuffer, หาทางเดินของศัตรูด้วย BFS และถังระเบิดต่อเนื่องด้วย Recursion
